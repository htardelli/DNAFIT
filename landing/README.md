# DNAFIT

Bem-vindo ao repositório do DNAFIT, uma plataforma de análise genética e fitness para ajudar pessoas a entenderem melhor o potencial do corpo e criar planos personalizados.

## Visão geral

DNAFIT combina:
- análise genética e predisposições
- perfil de condicionamento físico
- estratégia de treino personalizada
- orientação nutricional orientada por dados

## Estrutura do projeto

- `index.html` — landing page inicial
- `styles.css` — estilos visuais do produto
- `script.js` — interações e efeitos da interface
- `README.md` — documentação do projeto

## Como visualizar localmente

Abra o arquivo `index.html` diretamente no navegador ou rode um servidor simples:

```bash
python -m http.server 8000
```

Depois acesse: `http://localhost:8000`
